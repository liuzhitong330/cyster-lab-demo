# Cyster Lab research demo

An independent, target-specific research note prepared by Cathy Liu for the UCSF Cyster Lab.

The interactive narrative examines how inflammatory conditions change the chemoattractant requirements for naive B-cell entry into lymph nodes, with a second interaction tracing the transcellular synthesis of the EBI2 ligand 7α,25-HC.

## Sources

- Chen KY et al., *Cell* (2025), PMID 39708807
- NCBI GEO series GSE281684
- Cyster Lab, UCSF
- UCSF recruitment JPF05949

## Note

The demo is a structured interpretation of public research findings. It does not represent a raw reanalysis of the approximately 1.7 GB ATAC-seq dataset.
